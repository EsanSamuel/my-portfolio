# Esan Samuel — Backend & AI Engineer

A single page portfolio built with Next.js, React, and TypeScript.

## Run locally

```sh
npm install
npm run dev
```

To create a production build, run `npm run build`, then `npm start`.

JobSmart and Sensory use screenshots supplied for this portfolio; the Sensory sidebar email is redacted. Afterword uses a stylized product representation. The Go HLS Transcoder and Go Payment Infrastructure are presented as API-only projects without frontend previews. JobSmart and Afterword stacks were checked against project materials available locally; Sensory's stack is based on details supplied by Esan.
